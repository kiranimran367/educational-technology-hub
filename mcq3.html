Multiple Choice Questions

Select the best answer. The correct answer is shown below each question for self study.

1. Which statement best describes instructional design and the addie model?A. A planned approach that supports teaching and learningB. Using devices without learning goalsC. Replacing every teacher with softwareD. Using the internet only for entertainment
Right answer: A. A planned approach that supports teaching and learning
2. What should guide the selection of a learning technology?A. The newest trendB. The learning outcome and learner needsC. The colour of the deviceD. The number of apps available
Right answer: B. The learning outcome and learner needs
3. Which is a good academic practice when using online resources?A. Copy without checkingB. Ignore the sourceC. Check reliability and acknowledge sourcesD. Use only the first search result
Right answer: C. Check reliability and acknowledge sources
4. What is an important role of the teacher when using technology?A. Provide guidance and evaluate learningB. Leave learners without supportC. Avoid feedbackD. Use tools without planning
Right answer: A. Provide guidance and evaluate learning
5. Which approach is most suitable for effective learning?A. Technology for decorationB. Purposeful use matched to the lessonC. More screen time in every lessonD. One tool for every learner and task
Right answer: B. Purposeful use matched to the lesson
