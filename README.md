# Technology in Education Lesson Plan

An eight week lesson plan website for BS 7th Semester.

## Prepared by
* Aleesha Irfan (2023-1717)
* Kiran Imran (2023-1718)

## Files
* `index.html` is the homepage.
* `week1.html` to `week8.html` contain weekly lesson plans.
* `mcq1.html` to `mcq8.html` contain weekly multiple choice practice.
* `short1.html` to `short8.html` contain weekly short answer questions.
* `style.css` contains the website design.

## Publish with GitHub Pages
1. Upload all files in this folder to the root of your GitHub repository.
2. Open repository Settings.
3. Open Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.
